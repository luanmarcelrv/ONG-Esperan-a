#ONG Esperança

Projeto web desenvolvido para a ONG Esperança, focado em tansformar vidas e comunidades.

## Tecnologias Utilizadas
- HTML5
- CSS3 (Grid e Flexbox)
- JavaScript

## Estrutura do Projeto
- 'html/': Páginas de aplicação
- 'css/': Estilos do projeto
- 'js/': Scripts e lógica da aplicação
- 'imagens/': Ficheiros de imagem
